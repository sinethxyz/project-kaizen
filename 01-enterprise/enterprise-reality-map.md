# Enterprise Reality Map

The Enterprise Reality Map is a representation of how the company **actually** produces outcomes.

It should include:

- customers
- products/services
- people and teams
- formal responsibilities
- informal influence
- processes
- systems
- data
- infrastructure
- decisions
- metrics
- incentives
- dependencies
- constraints
- external actors

It must include unofficial reality:

- hidden spreadsheets
- manual workarounds
- duplicate records
- informal approvals
- undocumented knowledge
- contradictory metrics
- systems people bypass
- dependencies nobody owns

The map is useful only if it reflects the enterprise people actually work inside, not the enterprise described in a presentation.
