# Enterprise Primitives

Large organisations appear infinitely complex, but many behaviours can be represented using a smaller set of recurring primitives.

## Core primitives

- **Entities** — customers, employees, suppliers, products, assets, teams
- **Events** — orders, payments, hires, incidents, approvals, changes
- **Information** — records, documents, messages, metrics, forecasts
- **Resources** — capital, time, inventory, compute, attention
- **Flows** — money, information, materials, authority, work
- **Rules** — policies, constraints, contracts, regulation
- **Decisions** — choices made under uncertainty
- **Actions** — work executed by humans or systems
- **Outcomes** — measurable consequences
- **Feedback** — information returned to influence future decisions

The value of these primitives is not theoretical neatness. They create a shared language for comparing very different enterprises without assuming those enterprises are identical.
