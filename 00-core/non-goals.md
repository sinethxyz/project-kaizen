# Non-Goals

Project Kaizen can expand indefinitely if every interesting idea is allowed into the model.

This file exists to stop that.

Persist is **not** trying to:

- model every aspect of human psychology;
- replace founders or management;
- automate every decision;
- prescribe constant change;
- employ every possible specialist;
- force every enterprise into one operating model;
- maximise technology adoption;
- turn every diagnosis into a large transformation programme;
- predict the future with certainty;
- treat agent output as truth;
- build a giant software platform before repeated field evidence justifies it;
- become attached to any current method, technology, service line, or business model.

The goal is narrower:

> **Understand enough of the enterprise to make better decisions about adaptation.**

That means the model should only become more complex when the additional complexity improves diagnosis, execution, falsifiability, or learning.

## Simplicity test

Before adding a new concept to Project Kaizen, ask:

> **Does this make the reasoning logic clearer, more falsifiable, or more executable?**

If not, leave it out.

Depth should exist underneath the system.

The surface should remain simple.
