# The Model Is Not the Truth

Project Kaizen should never become a doctrine that survives merely because it is elegant.

> **The model is not the truth. The model is a machine for finding the truth.**

The loop is:

```text
MODEL
↓
ATTACK
↓
CONTRADICTIONS
↓
NEW EVIDENCE
↓
UPDATE
↓
TEST AGAIN
↺
```

Test the model against:

- customers
- operators
- competitors
- economics
- technical reality
- organisational behaviour
- historical evidence
- outcomes

A claim that fails should be changed or deleted.

A company about adaptation should have a strategy designed to be falsified and adapted.
