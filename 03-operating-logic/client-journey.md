# Possible Client Journey

This is an implication of the model, not a fixed commercial decision.

```text
INITIAL PROBLEM / QUESTION
↓
DIAGNOSIS
↓
ENTERPRISE REALITY MAP
↓
CONSTRAINT / OPPORTUNITY MAP
↓
ROUTING
↓
DEPLOYMENT — IF JUSTIFIED
↓
MEASUREMENT
↓
LEARNING
↓
ONGOING IMPROVEMENT — IF VALUABLE
```

The diagnosis should create standalone value. A client should receive a clearer model of reality even if no deployment contract follows.
