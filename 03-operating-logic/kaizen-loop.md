# Kaizen Loop

```text
SEE
↓
UNDERSTAND
↓
DECIDE
↓
IMPROVE
↓
MEASURE
↓
LEARN
↺
```

## See
Observe reality rather than assumptions.

## Understand
Build a model explaining why the outcome exists.

## Decide
Choose the highest-leverage intervention given evidence, economics, and constraints.

## Improve
Change the system.

## Measure
Compare the result with the baseline and expected mechanism.

## Learn
Update the model and repeat.

Project Kaizen should be applied both to clients and to Persist itself.
