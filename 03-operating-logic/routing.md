# Routing

Once a diagnosis is credible, the next question is:

> **What capability does this problem actually require?**

Routing may select:

- internal operator
- external specialist
- technology vendor
- cloud/compute provider
- legal/privacy support
- ERP/domain expert
- organisational specialist
- data or software engineer
- AI/ML engineer
- no intervention

Routing should consider:

- required expertise
- industry context
- jurisdiction
- confidentiality/security
- cost
- urgency
- availability
- integration dependencies
- previous outcomes

The long-term objective is to improve routing quality with evidence rather than intuition alone.
