# Diagnosis Before Prescription

> **Before transformation comes diagnosis.**

Technology-led firms naturally develop solution bias. Project Kaizen attempts to create a neutral starting point.

Trace symptoms downward:

```text
SYMPTOM
↓
PROCESS
↓
INFORMATION
↓
SYSTEM
↓
ORGANISATION
↓
ROOT CONSTRAINT
```

A useful question is:

> **Where does this problem first become inevitable?**

Three conclusions are valid:

```text
PROBLEM FOUND
→ intervene

FOUNDATIONS HEALTHY + OPPORTUNITY
→ consider new capability

NOTHING URGENT
→ do nothing unnecessary
```

If every diagnosis produces a project, neutrality is fiction.
