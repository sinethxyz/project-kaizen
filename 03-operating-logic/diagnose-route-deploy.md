# Diagnose → Route → Deploy

The cleanest operational abstraction is:

```text
ENTERPRISE
↓
DIAGNOSE
↓
ROUTE
↓
DEPLOY
↓
MEASURE
↓
LEARN
↺
```

## Diagnose

Understand what is actually happening and identify the highest-leverage constraint or opportunity.

## Route

Determine which capabilities, people, partners, technologies, and sequence are required.

## Deploy

Assemble the right intervention and execute it.

## Measure

Compare outcomes with an explicit baseline and expected mechanism.

## Learn

Update the enterprise model, routing logic, specialist knowledge, and future hypotheses.

The problem selects the capability. The capability does not select the problem.
