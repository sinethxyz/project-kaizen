# Operator Pods

An operator pod is a temporary team assembled around the diagnosed problem.

Examples:

```text
PROBLEM:
fragmented finance data + broken ERP integration

POD:
ERP architect
+ data engineer
+ finance operations specialist
```

```text
PROBLEM:
healthy support process but slow knowledge retrieval

POD:
AI engineer
+ knowledge systems specialist
+ support operations expert
```

```text
PROBLEM:
technology works; incentives create failure

POD:
transformation operator
+ organisational/operations specialist
```

The problem determines the pod.
