# Capability Routing Logic

Routing should become evidence-informed over time.

A simple sequence:

```text
DIAGNOSIS
↓
CAPABILITIES REQUIRED
↓
CONSTRAINTS
↓
CANDIDATE SPECIALISTS / PARTNERS
↓
POD DESIGN
↓
DEPLOY
↓
OUTCOME
↓
UPDATE ROUTING KNOWLEDGE
```

The routing model should learn from actual outcomes while preserving human judgment.

A highly rated specialist in one environment may be wrong for another. Context matters.
