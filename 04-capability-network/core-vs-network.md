# Core vs Network

## Keep core

Capabilities that define Persist should remain tightly owned:

- enterprise understanding
- diagnosis
- client relationship
- orchestration
- quality standards
- measurement
- knowledge capture
- model governance

## Route from network when appropriate

Variable specialist depth may include:

- AI/ML
- ERP
- networking
- cybersecurity
- cloud
- data architecture
- finance operations
- privacy/legal
- organisational design
- industry-specific expertise
- robotics or future technologies

The exact boundary should be tested against economics, security, availability, and delivery quality.
