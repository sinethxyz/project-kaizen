# Capability Network

If the enterprise is the centre of gravity, the problem space can be much broader than AI.

Persist therefore should not assume it must employ every specialist full-time.

A possible architecture is:

```text
CORE TEAM
enterprise understanding
+ diagnosis
+ orchestration
+ client trust
+ quality control
+ measurement
+ learning

        ↓

CURATED CAPABILITY NETWORK
specialist depth when required
```

The core owns the brain and accountability. The network supplies variable specialist depth.
