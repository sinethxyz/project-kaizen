# Specialist Network

The network should not be a generic freelancer directory.

It should be curated around demonstrated capability and trust.

A specialist profile may include:

- skills
- depth of expertise
- industry experience
- jurisdictions
- languages
- security/compliance constraints
- availability
- cost
- working style
- previous deployments
- measured outcomes
- reliability
- references

Over time the network becomes more valuable if routing decisions can be informed by actual delivery history.
