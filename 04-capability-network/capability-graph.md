# Capability Graph

A capability graph represents the relationship between problems and available expertise.

```text
PROBLEM
↓
REQUIRED CAPABILITIES
↓
CANDIDATE PEOPLE / FIRMS / VENDORS
↓
CONSTRAINT FILTERS
↓
PROPOSED POD
```

Relevant constraints may include:

- jurisdiction
- regulation
- security
- client technology stack
- industry experience
- urgency
- cost
- availability
- working style
- previous outcomes

The graph should help routing without pretending that human expertise can be reduced to a single score.
