# Moat

The language is not a moat.

Competitors can copy `Business first. Systems second. Technology third.` immediately.

A real moat could emerge from compounding assets:

```text
ENTERPRISE OBSERVATIONS
+
PATTERN LIBRARY
+
OUTCOME DATA
+
ROUTING KNOWLEDGE
+
SPECIALIST NETWORK
+
CLIENT TRUST
+
INTERNAL TOOLS
```

Over time Persist may become better at answering:

- which symptoms usually indicate which root causes?
- which prerequisites matter before an intervention?
- which specialists work in which environments?
- which sequences of change tend to succeed?
- which interventions fail under which conditions?

The moat must be earned through outcomes and disciplined learning, not declared in advance.
