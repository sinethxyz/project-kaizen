# Pattern Library

The pattern library captures recurring enterprise structures without pretending every company is the same.

Potential pattern classes:

- fragmented ownership
- metric incoherence
- knowledge monopoly
- founder bottleneck
- incentive conflict
- organisational sediment
- integration debt
- shadow-system dependence
- premature automation
- AI-before-data
- centralisation resistance
- transformation fatigue

Each pattern should contain:

- observable signals
- plausible causes
- alternative explanations
- common prerequisites
- interventions tried
- outcomes observed
- contexts where the pattern does not apply
