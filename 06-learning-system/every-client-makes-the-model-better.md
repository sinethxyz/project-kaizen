# Every Client Makes the Model Better

An engagement can produce more than revenue.

It can produce structured learning about:

- symptoms
- root constraints
- dependencies
- power structures
- intervention choices
- sequencing
- adoption
- cost
- time-to-value
- outcomes
- failure modes

The useful long-term question is:

> Under conditions X, Y, and Z, which interventions tend to work, fail, or require prerequisites?

Do not assume every observation generalises. Repetition and context matter.
