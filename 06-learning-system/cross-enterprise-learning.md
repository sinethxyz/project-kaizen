# Cross-Enterprise Learning

Cross-enterprise learning is useful only when context and confidentiality are respected.

Ask:

- is this pattern truly recurring?
- are the companies comparable enough for the inference?
- which variables differ?
- is the pattern causal or merely correlated?
- can the learning be represented abstractly without exposing client-specific information?

A pattern such as `founder approval bottleneck` can generalise conceptually without transferring another client's private details.

Prefer aggregated or anonymised knowledge where appropriate and contractually permitted.
