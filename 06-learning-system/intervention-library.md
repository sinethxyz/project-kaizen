# Intervention Library

The intervention library records what Persist has attempted and under what conditions.

Intervention classes may include:

- process redesign
- organisational redesign
- system integration
- data foundation work
- observability
- analytics
- deterministic automation
- optimisation
- ML
- generative AI
- agentic systems
- infrastructure change
- vendor replacement
- no intervention

For each intervention, record prerequisites, risks, cost range, time-to-value, adoption requirements, failure modes, and observed outcomes.
