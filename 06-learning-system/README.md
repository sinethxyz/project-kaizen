# Learning System

The long-term opportunity is not only to complete transformations. It is to make each transformation improve future enterprise understanding.

```text
MORE CLIENTS
↓
MORE ENTERPRISE OBSERVATIONS
↓
BETTER PATTERNS
↓
BETTER DIAGNOSIS
↓
BETTER ROUTING
↓
BETTER DEPLOYMENT
↓
BETTER OUTCOMES
↓
MORE LEARNING
↺
```

This compounding must never come at the expense of client confidentiality, contractual obligations, privacy, or factual discipline.
