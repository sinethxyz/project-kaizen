# Future Enterprise Model

The long-term asset should not be described too early as `our own LLM`.

The real asset is an enterprise intelligence architecture that may use multiple models.

It could eventually combine:

- structured enterprise graph
- historical state
- evidence ledger
- hypothesis graph
- outcome memory
- capability graph
- intervention library
- retrieval over client-authorised knowledge
- specialised AI agents
- human review

Models will change. The enterprise representation and learning system should be able to survive model replacement.

> **Persist should compound its understanding of enterprises faster than technology changes around them.**
