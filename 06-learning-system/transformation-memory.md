# Transformation Memory

For every engagement, record a structured before-and-after history.

Suggested fields:

- enterprise context
- initial question
- baseline
- evidence collected
- hypotheses considered
- diagnosis
- rejected explanations
- routing decision
- intervention
- capabilities deployed
- expected mechanism
- outcome
- unexpected effects
- post-mortem
- model updates

Transformation memory should make future reasoning auditable rather than dependent on individual consultant memory.
