# Living Enterprise Model

The enterprise should be modelled as a changing system, not a static diagram.

```text
STRUCTURE
+
SYSTEMS
+
DATA
+
ECONOMICS
+
PEOPLE
+
INCENTIVES
+
POWER
+
HISTORY
+
BEHAVIOUR
+
MARKET
+
TECHNOLOGY
```

The model should update as new evidence arrives.

It should be able to answer questions such as:

- what is producing the current outcome?
- what changed recently?
- what is path-dependent?
- which actors benefit from the current state?
- which constraints are technical versus organisational?
- what would likely happen if a proposed intervention were deployed?

A useful enterprise model is always provisional.
