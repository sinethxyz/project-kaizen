# Power Layer

The formal org chart does not fully describe power.

Map:

- formal authority
- informal influence
- budget control
- information control
- veto rights
- founder proximity
- knowledge monopolies
- dependency relationships
- coalitions
- ability to delay or accelerate change

A transformation can be technically correct and still fail because it threatens power, status, control, or incentives.

The question is not only `who owns this process?` but also `who can actually change it, stop it, or make others comply?`
