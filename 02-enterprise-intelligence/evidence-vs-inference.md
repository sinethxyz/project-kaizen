# Evidence vs Inference

Enterprise intelligence must clearly distinguish what is known from what is inferred.

```text
EVIDENCE
≠
INFERENCE
≠
SPECULATION
```

A useful evidence hierarchy is:

1. direct system evidence — transactions, logs, financial records, workflow data
2. observed behaviour — actual approvals, meetings, hand-offs, actions
3. multiple independent human reports
4. single human report
5. management narrative
6. model inference

This is not an absolute ranking for every case, but it prevents the model from confusing persuasive stories with reality.

Every important hypothesis should state what evidence supports it, what evidence challenges it, and what would falsify it.
