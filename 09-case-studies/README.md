# Enterprise Adaptation Library

These cases are not morality stories and should not be simplified to fit Project Kaizen.

Every case should ask:

```text
WHAT CHANGED?

WHAT APPEARED TO CHANGE?

WHAT ACTUALLY CHANGED?

WHAT DID MANAGEMENT BELIEVE?

HOW DID THE ENTERPRISE RESPOND?

WHAT HAPPENED?

WHAT ALTERNATIVE EXPLANATIONS EXIST?

WHAT PATTERN CAN WE REUSE?
```

Counterexamples belong here too.
