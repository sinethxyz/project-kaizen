# Netflix and Cloud

The useful conceptual sequence is:

```text
OPERATIONAL / ARCHITECTURAL PROBLEM
↓
DIAGNOSIS
↓
NEW REQUIREMENTS
↓
CLOUD SELECTED
↓
ARCHITECTURAL + ORGANISATIONAL CHANGE
```

## Pattern
> **Cloud was a prescription, not the diagnosis.**

This case is useful because it illustrates the reasoning order Project Kaizen prefers: understand the constraint first, then select the enabling technology.
