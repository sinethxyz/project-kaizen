# Consulting and Systems Integrators

Project Kaizen sits adjacent to existing categories that already begin from broad enterprise problems:

- management consulting
- technology consulting
- systems integration
- business-process transformation
- managed services
- enterprise architecture

This is the strongest challenge to any claim that `continuous enterprise transformation` is automatically a new category.

## Questions to test

- what does Project Kaizen do that a strong integrator does not?
- does paid neutral diagnosis create a different trust relationship?
- can routing through a specialist network be faster or more flexible than traditional staffing?
- can the enterprise learning system create compounding capability that normal project delivery does not?
- can the model avoid consultancy economics?

Do not declare differentiation until customer behaviour demonstrates it.
