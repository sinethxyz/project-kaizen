# Technology Waves

A broad enterprise technology progression:

```text
1960s–1980s
enterprise computing / databases / MRP

↓
1980s–1990s
ERP

↓
1990s
Internet / Web

↓
late 1990s–2000s
SaaS

↓
2000s–2010s
cloud

↓
2000s–2010s
Big Data

↓
2010s
modern ML / deep learning

↓
2020s
generative AI

↓
2020s
agentic / increasingly autonomous systems

↓
???
```

These waves overlap. They are not clean replacements.

The point is that strategic attention moves while older technologies become part of the substrate.
