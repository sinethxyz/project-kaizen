# Wave Economics

A useful way to interpret technological waves is to ask which friction each reduces.

```text
DATABASES
→ memory / retrieval friction

INTERNET
→ communication / distribution friction

ERP
→ coordination friction

SAAS
→ software adoption friction

CLOUD
→ infrastructure provisioning friction

BIG DATA
→ large-scale information processing constraints

ANALYTICS
→ understanding friction

ML
→ prediction friction

GENERATIVE AI
→ certain forms of cognitive friction

AUTONOMOUS SYSTEMS
→ potentially decision / execution friction
```

The recurring questions are:

> **What just became cheaper, faster, or newly possible?**

and:

> **What does that actually change for this enterprise?**
