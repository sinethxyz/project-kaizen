# Correct Diagnosis

```text
CHANGE
↓
WHAT ACTUALLY CHANGED?
↓
WHY DOES IT MATTER?
↓
WHICH PART OF THE ENTERPRISE IS MISALIGNED?
↓
WHAT SHOULD CHANGE?
↓
WHICH INTERVENTION FITS?
↓
WHICH TECHNOLOGY HELPS?
↓
IMPLEMENT
↓
MEASURE
↓
LEARN
```

This is the core reasoning pattern Project Kaizen is trying to institutionalise.
