# Evidence

This folder exists to challenge Project Kaizen, not decorate it.

It contains competitor references, technology history, case studies, reusable patterns, source lists, and a falsification log.

Use it to ask:

- what supports the model?
- what contradicts it?
- what is merely an analogy?
- what alternative explanation exists?
- what new evidence should change the thesis?

Historical cases should not be reduced to morality stories.

Competitors should not be caricatured.

If evidence weakens a claim, update the claim.
