# Agent Roles

The agent system should stay small.

Six roles are enough to create useful disagreement without turning the system into an agent zoo.

Each role looks at the same enterprise evidence from a different angle. Their purpose is not to vote on truth. Their purpose is to expose contradictions, weak assumptions, missing evidence, and alternative explanations.

## 1. Systems Agent

Examines systems, workflows, data, infrastructure, dependencies, ownership, process design, and bottlenecks.

Core question:

> **What mechanism inside the enterprise is producing the observed outcome?**

## 2. Economics and Customer Agent

Tests economic value and customer value together.

Looks at margins, cost, pricing, capital allocation, opportunity cost, unit economics, customer outcomes, and whether the proposed intervention solves something anyone actually values.

Core question:

> **Does this matter economically, and does it improve something the customer actually cares about?**

## 3. Human and Power Agent

Examines incentives, adoption, trust, resistance, morale, communication, formal authority, informal influence, veto power, budgets, information control, and coalitions.

It reasons from observable behaviour rather than amateur psychological labels.

Core question:

> **What human or power structure could explain the problem or prevent the solution from working?**

## 4. History and Founder Agent

Reconstructs how the company became what it is.

Looks at founding assumptions, founder decision patterns, path dependence, acquisitions, crises, old systems, organisational sediment, and decisions that still shape the present.

Core question:

> **Which parts of today's enterprise are consequences of its history rather than deliberate current design?**

## 5. Technology Agent

Evaluates technology without assuming technology is the answer.

It must make both cases:

1. the strongest case for using a technology
2. the strongest case for not using it

It compares AI, software, infrastructure, automation, vendors, existing systems, and non technical alternatives where relevant.

Core question:

> **What capability is actually required, and is technology the best way to provide it?**

## 6. Red Team Agent

Attacks the entire diagnosis.

It searches for contradictions, counterexamples, alternative causal explanations, hidden assumptions, missing evidence, and reasons the current model could be wrong.

It has explicit permission to conclude:

> **The diagnosis is wrong. Start again.**

Core question:

> **What would have to be true for our current understanding of the enterprise to be wrong?**

## The rule

Agents do not decide company truth.

They create pressure on the model.

```text
EVIDENCE
↓
SIX PERSPECTIVES
↓
DISAGREEMENT
↓
CONTRADICTIONS
↓
BETTER QUESTIONS
↓
MORE EVIDENCE
↓
BETTER ENTERPRISE MODEL
↺
```

> **AI proposes. Evidence constrains. Humans decide. Outcomes judge.**
