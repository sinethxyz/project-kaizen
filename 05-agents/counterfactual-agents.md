# Counterfactual Agents

Counterfactuals expose hidden dependencies and assumptions.

Useful prompts:

- If AI did not exist, how would we solve this problem?
- If this company were founded today, would this process exist?
- If the founder disappeared for six months, what would stop?
- If revenue doubled tomorrow, which system or team would fail first?
- If revenue halved tomorrow, which structure becomes unsustainable?
- If this department disappeared, what would actually break?
- If a competitor had perfect visibility into our systems, where would it attack?
- If the proposed intervention were forbidden, what alternative would we choose?

Counterfactuals should generate hypotheses, not pretend certainty about alternate worlds.
