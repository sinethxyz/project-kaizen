# Adversarial Enterprise Intelligence

The AI layer should not exist to produce one confident answer.

It should improve the enterprise model by generating competing explanations, finding contradictions, asking better questions, demanding evidence, and updating confidence.

> **Do not ask one model for the truth. Create a system where different perspectives try to disprove one another.**

Project Kaizen uses six core agent roles:

1. Systems Agent
2. Economics and Customer Agent
3. Human and Power Agent
4. History and Founder Agent
5. Technology Agent
6. Red Team Agent

The desired loop is:

```text
ENTERPRISE EVIDENCE
↓
SIX PERSPECTIVES
↓
COMPETING HYPOTHESES
↓
CONTRADICTIONS
↓
NEW QUESTIONS
↓
NEW EVIDENCE
↓
UPDATED MODEL
↺
```

The agents are not six autonomous authorities. They are six reasoning perspectives applied to the same evidence.

Their job is to create disciplined disagreement and expose weak assumptions.

They do not decide what is true.

> **AI proposes. Evidence constrains. Humans decide. Outcomes judge.**
