# Agents

Project Kaizen uses six core reasoning roles.

1. **Systems**
2. **Economics and Customer**
3. **Human and Power**
4. **History and Founder**
5. **Technology**
6. **Red Team**

These are perspectives, not six autonomous decision makers.

They attack the same enterprise model from different angles.

```text
ENTERPRISE MODEL
↓
SIX PERSPECTIVES
↓
DISAGREEMENT
↓
CONTRADICTIONS
↓
BETTER QUESTIONS
↓
NEW EVIDENCE
↓
UPDATED MODEL
↺
```

Methods such as counterfactuals, pre mortems, contradiction mining, interrogation, and structured jury review are tools used by these six roles. They are not additional agents.
