# LLM Layer

The LLM layer is separate from the agent layer.

The LLM is the reasoning substrate used to represent the enterprise, organise context, form hypotheses, track evidence and uncertainty, and generate better questions.

The agents are adversarial perspectives that attack that representation.

```text
ENTERPRISE EVIDENCE
↓
LLM REASONING LAYER
↓
ENTERPRISE MODEL
↓
AGENT PRESSURE
↓
UPDATED MODEL
```

Project Kaizen does not require Persist to train a proprietary foundation model from day one.

The durable asset is the enterprise reasoning architecture, context, memory, evaluation logic, patterns, and outcomes. The underlying model provider can change.

> **Do not confuse the LLM with the enterprise model.**
